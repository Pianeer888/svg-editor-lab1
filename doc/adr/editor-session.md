# 编辑会话的职责

`EditorSession` 持有当前文档、默认保存路径和编辑历史。这三项共同定义一次会话。成功完成初始化、读入、保存或调整画布尺寸后，依 Phase 1 规则清空并阻断旧历史。文档读入失败、保存失败或画布尺寸非法时，调用者仍能使用原文档、原文件路径和原历史。

`Cli` 负责解析参数、构造命令、分发和显示。编辑命令仍负责操作图形及回滚，`DocumentStore` 负责文件访问。会话通过注入的存储接口运行，可以用测试替身直接验证异常路径。现有保存点包装器继续在成功读写时更新树标签。

这次提取针对已经存在的状态更新规则。命令注册和树输出保留在 CLI，未来有独立的呈现需求时再评估拆分。通过会话单元测试与三组 CLI 回放检查行为兼容性。

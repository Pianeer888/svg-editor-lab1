# 树标签的保存点语义

**决定。** `ModifiedStar` 按文档实例保存最近成功读取或写出的图形快照。每行比较图形类型、几何和样式、父容器及同级位置。新建节点立即标星，撤销回保存点时星号消失。另一次编辑恢复同样的内容也会消除星号。读取或保存成功后，`SavePointStore` 通知标签更新快照，失败时保留原保存点。

**传播与顺序。** 修改子图形的属性时只标记该行。如果移动容器改变了多个子图形的坐标，则这些子图形各自标星。同级顺序变化会标记位置改变的行。已删除的图形没有可显示的行。`(box)` 在两个默认装配中先注册，跟随其后的 `*` 由另一个实例提供。`svg (w×h)` 是渲染器的画布标题，现有图形行接口从画布子节点开始。

**理由。** 内容比较能区分仍有改动与已经撤销的编辑，而且同一套逻辑适用于 undo 和 redo。把保存点通知放在 `DocumentStore` 包装层，CLI 和撤销历史可以继续使用原有接口。采用逐行比较时，画布级修改和删除不会产生全局星号。
